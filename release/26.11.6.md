## Highlights (unchanged since 26.11.5)

### Access keys

Protect pages with frontmatter. Bodies are encrypted before upload; visitors see a teaser and unlock in the browser with a key.

| Capability | Details |
| --- | --- |
| Page protection | `access: protected`; optional `teaser` |
| Independent scopes | e.g. `access_scope: docs` / `members` |
| Folder inheritance | Folder `index.md` covers that folder and children |
| Dashboard | Issue, multi-scope grant, and revoke keys |

```yaml
---
title: Docs
access: protected
access_scope: docs
teaser: Read the full note after you unlock.
---
```

## Full feature list

### Publish & hosting

- Right-click a folder → Publish; local Preview
- **Guest:** no account (7-day rolling expiry); claim to Free and keep the same URL
- **Free:** 200 MB · **Personal:** 5 GB, custom domain + HTTPS, history & rollback
- Global CDN share links; Unpublish

### Site chrome (Advanced)

- Title, logo, favicon · nav links · Subscribe form (Audience in Dashboard; CSV / Markdown export)

### Custom domain (Personal)

- Bind hostname, DNS setup, automatic certificate · optional auto-DNS (e.g. Aliyun)

### Content & build

- Wikilinks, callouts, local images, Mermaid, KaTeX · search / graph / backlinks when the theme supports them · local build, static upload

### Account & localization

- Plan status in the sidebar · Settings → MDFriday for billing · English and Simplified Chinese UI
