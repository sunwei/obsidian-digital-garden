# MDFriday Digital Garden v26.11.5

**Date:** 2026-11-20  
**Plugin id:** `mdfriday-garden`  
**Engine:** `@mdfriday/core@26.11.1`  
**Requires:** Obsidian 1.13.0+ (desktop)

Right-click a folder to publish a wiki or digital garden — no Git, no account required for a first try. This release brings **Access keys**, **Commerce (selling unlocks)**, and the **Beer-source wiki theme line** to production.

---

## Highlights

### Access keys

Protect pages with frontmatter. Bodies are encrypted before upload; visitors see a teaser and unlock in the browser with a key.

| Capability | Details |
| --- | --- |
| Page protection | `access: protected`; optional `teaser` |
| Independent scopes | e.g. `access_scope: docs` / `members` — authorize pages separately |
| Folder inheritance | A folder’s `index.md` applies to that folder and its children |
| Public home + locked pages | Keep the homepage public while locking detail pages |
| Dashboard key management | Issue, multi-scope grant, and revoke keys; the sidebar links to Dashboard |
| Guest first publish | Root-level protection can return a shared key on first publish |
| Plans | Available on Guest / Free / Personal (sign in to manage keys) |

Example:

```yaml
---
title: Docs
access: protected
access_scope: docs
teaser: Read the full note after you unlock.
---
```

### Commerce (selling access)

Sell unlocks on top of protected content. Configure products in the Dashboard; readers buy on the live site and receive a key.

| Capability | Details |
| --- | --- |
| Sidebar Selling | Advanced → enable selling for this site |
| Dashboard Sales | Contact email → connect Creem → create offers bound to access scopes |
| Reader journey | Buy on the locked page → get a key → unlock the matching scope |
| Commerce pages | Auto `privacy` / `pricing` / `purchase` shells; extend with root `privacy.md` / `pricing.md` |
| Plan | Selling requires **Personal** |
| Hosting | Works on share links and custom domains (domain needs Personal) |

## Full feature list

### Publish & hosting

- Right-click a folder → Publish; local Preview
- **Guest:** publish without an account (7-day rolling expiry); claim to Free and keep the same URL
- **Free:** 200 MB permanent storage while the account stays active
- **Personal:** 5 GB, custom domain + automatic HTTPS, publish history & rollback
- Global CDN share links; Unpublish

### Site chrome (Advanced)

- Title, logo, and favicon (pick images from the vault)
- Navigation links (wiki header)
- **Subscribe:** email form on the site; Audience in Dashboard; export CSV / Markdown

### Custom domain (Personal)

- Bind your hostname, DNS setup flow, automatic certificate
- Optional automatic DNS via supported credential backends (e.g. Aliyun)

### Content & build

- Wikilinks, callouts, local images, Mermaid, KaTeX
- Chinese and English search; graph / backlinks when the theme supports them
- Build runs locally; only the finished static site is uploaded

### Account & plans

- Plan status and upgrade prompts in the sidebar
- Billing, domains, and projects under Settings → MDFriday

### Localization

- English and Simplified Chinese UI
